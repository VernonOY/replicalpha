# replicalpha — frontend prototype

Personal research-paper reproduction timeline. Dark, dense, factor-aware.

## Files
- `replicalpha.html` — entry point. JSX is inlined into the HTML (Babel can't fetch sibling .jsx files in the sandbox without a preview token), so to edit: change the source `*.jsx` files, then re-run the bundler.
- Source modules (load order — see `build_bundle.py`):
  - `data.jsx` — sample papers / verdict colors
  - `ui.jsx` — shared atoms (Mono, Spark, etc.)
  - `tweaks-panel.jsx` — tweaks panel + hooks
  - `timeline.jsx` — timeline page
  - `run-detail.jsx` — verdict / evidence / red-team / code / report tabs
  - `ide.jsx` — code IDE drawer
  - `ai-search.jsx` — AI paper-search drawer
  - `custom-upload.jsx` — custom paper upload drawer
  - `pages.jsx` — Factors / Library / Upload / Compare pages
  - `api.jsx` — **v0.4** fetch client targeting FastAPI (`window.api`)
  - `analysis.jsx` — **v0.4** Analysis page (`window.AnalysisPage`) for `/runs/[id]/analysis`
  - `app.jsx` — App shell + router (must be last)
- `v03-additions.compiled.js` / `v03-additions.jsx` — pre-compiled v0.3 page set (Monitor / Portfolio / Settings / Search / Profile / NotFound / CommandPalette / NotificationsBell). Inlined into the HTML in a separate non-Babel `<script>` block earlier in the document.
- `bundle.jsx` — generated concatenation of the modules (kept for diffing). Regenerated by `build_bundle.py`.
- `replicalpha.html.backup-pre-v0.4-pt1` — snapshot taken before the v0.4 Part 1 (Analysis page) wiring.

## Bundle
After editing any `.jsx`, re-run the inliner:

```bash
python3 frontend/build_bundle.py
```

The script is idempotent: it concatenates every module listed in `LOAD_ORDER` with `// ===== <name> =====` separators, writes `bundle.jsx`, and rewrites the contents of the `<script type="text/babel" data-presets="react">…</script>` block in `replicalpha.html`.

To override the backend URL at runtime (e.g. when serving the HTML from a different origin), set `window.__API_BASE` before the bundle loads:

```html
<script>window.__API_BASE = 'https://api.example.com';</script>
```
